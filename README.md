# Crow Game Studio documentation

Public policies and documentation for apps published by Crow Game Studio.

## Pages

- [Documentation home](https://ejherran.github.io/crow-game-studio-docs/).
- [LalaCalc Privacy Policy](https://ejherran.github.io/crow-game-studio-docs/lalacalc/privacy-policy/).

These addresses become available after GitHub Pages is enabled and the first deployment completes.

## Structure

```text
index.html
.nojekyll
lalacalc/
  privacy-policy/
    index.html
```

Add each app under its own stable directory. Put each policy or documentation page in a directory containing an `index.html` file. Keep published policy URLs stable when adding or updating apps. Publish completed pages only.

All content in this repository is public. Each app's policy must describe that app's actual data handling and identify Crow Game Studio and its privacy contact.

## Hosting

In this repository's **Settings > Pages**, select **Deploy from a branch**, branch **main**, folder **/ (root)**, then save. Use HTTPS and verify the published policy opens without authentication before submitting its URL in a store listing.

The website uses static HTML and CSS without a build step or extra analytics scripts. GitHub Pages processes visitor requests under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
